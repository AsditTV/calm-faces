# Site du jeu (page + politique de confidentialité)

Fichiers statiques, aucune ressource externe (pas de police Google, pas de traceur, pas de cookie) :
`index.html` (page du jeu), `privacy.html` (politique de confidentialité EN + FR), `style.css`, `img/`.

## À remplir avant de publier la fiche du store
Dans `privacy.html` et `index.html`, les champs surlignés :
- `LEGAL NAME OF THE PUBLISHER` / `NOM LÉGAL DE L'ÉDITEUR` : ton nom (ou ta micro-entreprise) tel qu'il apparaîtra sur le store ;
- `COUNTRY` / `PAYS` ;
- `SUPPORT_EMAIL` : une adresse dédiée au jeu (pas ta boîte perso).
La politique est un **modèle sérieux, pas un avis juridique** : à faire relire si le jeu devient payant.

## Mise en ligne
Hébergement prévu : GitHub Pages, dépôt public séparé `AsditTV/calm-faces` (adresse
`https://asdittv.github.io/calm-faces/`). Le dépôt du jeu reste à part.
Mettre à jour : copier le contenu de `site/` dans ce dépôt, commit, push : la page se met à jour en ~1 min.
